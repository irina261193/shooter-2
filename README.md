# ENGLISH SECRET BASE

Детский игровой урок английского по упражнениям 8–12 (печатные страницы 69–70), 60 минут по PPP. React + TypeScript + Vite, без сервера и API-ключей.

## Запуск

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Сборка в `dist/`, относительный `base: './'`. Workflow `.github/workflows/pages.yml` публикует `main` на GitHub Pages при выборе **Settings → Pages → GitHub Actions**.

## Управление

Start lesson включает звук по действию пользователя. Выбери мишень, произнеси ответ, нажми «Я сказал» / «Ответ произнесён», затем FIRE. Space активирует игровую мишень только вне полей, кнопок и списков. Неправильный ответ разрешает повтор, повторное попадание не начисляет энергию. Каждая миссия даёт максимум один значок.

Учитель открывает панель вверху: подробный план 0–60, реплики и результаты, переход к любой миссии, пропуск, настройки речи и эффекта, ключи только текущей миссии после предупреждения. Режим демонстрации использует A/B/C, удалённое управление не требуется. Устная речь отмечается вручную, микрофон и распознавание речи не используются. Семьи агентов вымышленные.

«Учебник» содержит полный исходный текст и исходную таблицу. Произношение в учебных карточках исправлено: worker /ˈwɜːkə/. Конструктор вопросов поддерживает перетаскивание и кнопки. Свободные вопросы принимает учитель вручную. Word Repair: скрой образец, напиши, проверь все пять слов. Кроссворд строится из общих координат: 22 клетки, 7×10; клик по подсказке выбирает слово, повторный клик в пересечении меняет направление; стрелки, Backspace и автопереход доступны. Ответы не появляются в клетках автоматически.

Сохранение в localStorage с версией схемы: миссия, задания, подсказки, поля, сетка, настройки и таймер. После перезагрузки восстановление только через Continue. New lesson начинает заново, Reset требует подтверждения. Таймер рекомендательный: план ровно 60 минут, фактическая длительность определяется учителем.

## Звук

Web Speech API выбирает английский голос en-GB, затем en-US; список обновляется по voiceschanged. Наличие и качество голосов зависят от браузера и устройства. Синтез речи не гарантирует работу без сети. При отсутствии голоса учитель читает вслух, задачи остаются доступными. Реальные голоса и передача звука в видеозвонке требуют проверки на устройстве пользователя.

`audioFiles` в `src/data.ts` позволяет сопоставить точный английский текст относительному пути MP3. Записей в комплекте нет. Эффекты синтезируются Web Audio API, речь и эффекты имеют отдельную громкость. Переходы, пауза и mute отменяют текущую речь.

Учебные данные и план редактируются в `src/data.ts`. Тесты проверяют геометрию и пересечения, непрерывный 60-минутный план, восемь раундов, проверку вопросов и отсутствие повторных наград.
